Guia Básico: Tag <section>

Aprenda de forma simples como organizar o conteúdo do seu site!

1. O que é a tag <section>?

A tag <section> serve para separar assuntos ou blocos em uma página da web.

Pense no seu site como um livro: a página inteira é o livro, e cada <section> é um capítulo novo. Cada capítulo deve ter o seu próprio título (usando <h2>, por exemplo).

2. Como usar no seu código

Veja abaixo um exemplo simples de como escrever no HTML:

<-- Exemplo de site com < sections > -->
    <main>

    <section>
    <h2>Sobre Mim</h2>
    <p>Olá! Estou aprendendo a criar sites com HTML.</p>
    </section>

    <section>
    <h2>Meus Hobbies</h2>
    <p>Gosto de ler, jogar e programar.</p>
    </section>

    </main>

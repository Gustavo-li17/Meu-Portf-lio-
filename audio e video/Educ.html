Tags <audio> e <video> no HTML

Aprenda como incorporar mídia nativamente na web sem necessidade de plugins externos.

Como Elas Funcionam?

Antes do HTML5, para reproduzir áudio ou vídeo na web, era necessário recorrer a plugins de terceiros, como o Adobe Flash Player. Com a chegada do HTML5, o suporte a arquivos multimídia tornou-se nativo nos navegadores modernos.

Ambas as tags funcionam como elementos de bloco que encapsulam o arquivo de mídia. Dentro delas, podemos definir várias origens (<source>) para garantir a compatibilidade, já que diferentes navegadores suportam diferentes formatos (como MP3 e OGG para áudio, ou MP4, WebM e OGV para vídeo).

A Tag <audio>

Utilizada para reproduzir arquivos de som. Veja um exemplo prático de implementação:

<audio controls>
    <source src="exemplo.mp3" type="audio/mpeg">
    <source src="exemplo.ogg" type="audio/ogg">
</audio>

A Tag <video>

Utilizada para reproduzir arquivos de vídeo e filmes. É muito similar à tag de áudio, mas inclui atributos visuais específicos como largura, altura e imagem de capa (poster).

<video width="640" height="360" controls poster="capa.jpg">
    <source src="filme.mp4" type="video/mp4">
    <source src="filme.webm" type="video/webm">
</video>

Atributos e Suas Funções

Abaixo estão listados todos os principais atributos que você pode utilizar para controlar o comportamento das mídias:

Atributo Se aplica a O que faz / Para que serve?
src Ambos Especifica o caminho (URL) do arquivo de áudio ou vídeo. (Pode ser substituído pela tag interna <source>).
controls Ambos Adiciona os controles nativos do navegador (botão Play/Pause, volume, barra de progresso, tela cheia). Sem ele, a mídia fica invisível ou inacessível a menos que controlada por JavaScript.
autoplay Ambos Faz com que a mídia comece a tocar automaticamente assim que a página carregar. Nota: A maioria dos navegadores bloqueia o autoplay de áudio se o som não estiver mutado.
loop Ambos Faz com que o áudio ou vídeo reinicie automaticamente do início sempre que chegar ao fim (reprodução contínua).
muted Ambos Inicia a reprodução do arquivo de mídia com o som desativado (mudo). Essencial se quiser usar o autoplay em vídeos de fundo.
preload Ambos Informa ao navegador como o arquivo deve ser carregado. Valores: none (não carrega até dar play), metadata (carrega só dados básicos como duração) ou auto (carrega o arquivo inteiro imediatamente).
width Apenas Vídeo Define a largura do player de vídeo em pixels.
height Apenas Vídeo Define a altura do player de vídeo em pixels.
poster Apenas Vídeo Especifica uma imagem que será exibida na tela enquanto o vídeo não for reproduzido ou enquanto estiver baixando.
playsinline Apenas Vídeo Indica que o vídeo deve ser reproduzido "inline" dentro do elemento, impedindo que dispositivos móveis (como iPhones) forcem a abertura automática do vídeo em tela cheia nativa.
